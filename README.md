# WORDER

An offline word game inspired by Ruzzle, built with Flutter.

## Features

- 100% offline gameplay
- Bilingual support (Italian & English)
- Multiple grid sizes (4x4, 5x5, 6x6, 7x7, 8x8)
- Configurable game duration (2', 3', 4', 5', infinite)
- Bonus tiles (Triple Word, Double Word, Triple Letter, Double Letter)
- Game history and persistence
- Share your results

## Getting Started

1. Install Flutter SDK
2. Run `flutter pub get` to install dependencies
3. Run `flutter run` to start the app

## Platforms Supported

- iOS
- Android
- Linux
- Windows
- macOS
